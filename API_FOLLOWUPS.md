# Отложенные изменения API

## № 7. Отзыв других собственных сессий

Возвращать идентификатор текущей сессии для предъявленного bearer либо признак `is_current` в списке сессий. Фронтенд сможет помечать текущую сессию и разрешать отзыв только остальных. Текущую сессию по-прежнему можно завершить через выход из аккаунта.

## № 17. Допустимый срок жизни ссылок доступа

Добавить в доступный фронтенду ответ API минимальный, максимальный и заданный по умолчанию TTL ссылки в секундах. Передавать только эти публичные значения конфигурации. После этого фронтенд сможет предложить допустимые сроки для конкретного сервера.
