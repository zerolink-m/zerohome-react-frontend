# API Specification - Stats Endpoints
# Date: 26.10.2026 (v2)
# New endpoints for application statistics

## Statistics Endpoints

All stats endpoints require **admin role** and are rate-limited to 20 requests per minute.

---

### Get All Statistics
GET /v1/stats
- Description: Get comprehensive application statistics
- Auth: Required (admin only)
- Rate limit: 20/min
- Query params:

- Response: {
    "success": true,

## Notes

1. All endpoints return 403 Forbidden if user is not admin
2. All endpoints are rate-limited to 20 requests per minute
3. Motion statistics period can be configured from 1 to 168 hours (1 week)
4. Active sessions are counted as sessions with activity in last 30 days
5. Performance metrics keep last 1000 samples per endpoint/method
6. Network statistics are cumulative since system boot
7. Recording statistics scan actual filesystem for .mp4/.mkv/.avi files
